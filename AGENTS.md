# Repository instructions

Read CONTRIBUTING.md before changing code. AI-assisted changes follow the same evidence and review rules.

- Keep edits within the requested scope and preserve other contributors' work.
- Preserve the separation between engine, game, showcase and mod kit.
- Verify behavior from evidence and identify assumptions. Do not claim clean-room provenance.
- Never commit game assets, binaries, decompiler exports or locally extracted lookup tables.
- Run the relevant checks and public-file audit before finishing.
- Keep the two ctw_plugin.h copies identical and public APIs append-only.
