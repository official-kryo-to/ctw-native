# Controls

The intro movie stops when any key, mouse button or controller button is held for more than a second.

| On foot | |
| --- | --- |
| W A S D / arrows | Move |
| Shift | Sprint |
| Ctrl | Walk |
| F / Enter | Get in a vehicle |
| Space / left mouse | Fire (aims at the nearest target in front, as the original does) |
| G / right mouse (hold) | Throw a grenade, molotov or flash bang: hold longer to throw further; drops a mine |
| Q / E | Previous / next weapon |
| Z | Sniper scope: zoom in or out (W A S D move the scope) |
| Tab | Weapon wheel |

| In a vehicle | |
| --- | --- |
| W / Up | Accelerate |
| S / Down | Brake, reverse |
| A D / Left Right | Steer |
| Space | Handbrake |
| W + S (stopped) | Burnout: steer to spin on the spot, let go of S to launch |
| H / Alt | Horn |
| F / Enter | Get out |
| Tab | Radio |

| Radio (Tab) | |
| --- | --- |
| A D / Left Right | Station |
| W S / Up Down / + - | Volume |
| Tab / Esc / Backspace | Close |

| Controller (Xbox layout; any SDL game controller) | |
| --- | --- |
| Left stick | Move (a light push walks) / steer |
| A (hold) | Sprint / handbrake |
| RT | Fire / accelerate |
| LT (hold) | Throw (hold longer to throw further) / brake, reverse |
| RT + LT (stopped) | Burnout |
| Y | Get in or out of a vehicle |
| LB / RB | Previous / next weapon |
| X (hold, in a vehicle) | Horn |
| Back / View | Weapon wheel on foot, radio in a vehicle |
| D-pad | Radio: station (left / right), volume (up / down) |
| R3 | Sniper scope zoom |
| Start / Menu | Pause menu (it also opens the mod menu) |
| B | Close the radio, the pause menu or the mod menu |

| Game | |
| --- | --- |
| F3 | Debug overlay |
| F4 | Mod menu (Esc closes it) |
| Esc | Pause menu: resume, mod menu, controls, quit |

| Enhancements mod | |
| --- | --- |
| V | Third-person camera |
| Mouse | Look around |
| C (held, in a vehicle) | Look behind |
| Mouse (PC aiming, when switched on) | Aim at the cursor; throws land on it |
| Mouse wheel (PC aiming) | Next / previous weapon |

| Cheat Example mod | |
| --- | --- |
| F7 | Spawn menu: vehicles and weapons (Enter spawns the first match) |
| Shift (in a vehicle) | Nitro, when switched on |
| F8 | Free camera |
| W A S D, mouse | Free camera: move, look |
| Space / E, Ctrl / Q | Free camera: up, down |
| Shift | Free camera: faster |
| Page Up / Page Down | Free camera: render distance |

| Multiplayer mod | |
| --- | --- |
| F9 | Host or join a game (name, address and port; Enter or Esc leaves a field) |
| T | Chat (Enter sends, Esc closes) |
