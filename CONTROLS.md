# Controls

| On foot | |
| --- | --- |
| W A S D / arrows | Move |
| Shift | Sprint |
| Ctrl | Walk |
| F / Enter | Get in a vehicle |

| In a vehicle | |
| --- | --- |
| W / Up | Accelerate |
| S / Down | Brake, reverse |
| A D / Left Right | Steer |
| Space | Handbrake |
| H / Alt | Horn |
| F / Enter | Get out |
| Tab | Radio |

| Radio (Tab) | |
| --- | --- |
| A D / Left Right | Station |
| W S / Up Down / + - | Volume |
| Tab / Esc / Backspace | Close |

| Game | |
| --- | --- |
| F3 | Debug overlay |
| F4 | Mod menu (Esc closes it) |
| Esc | Quit |

| Enhancements mod | |
| --- | --- |
| V | Third-person camera |
| Mouse | Look around |
| C (held, in a vehicle) | Look behind |

| Cheat Example mod | |
| --- | --- |
| F7 | Vehicle spawner (Enter spawns the first match) |
| Shift (in a vehicle) | Nitro, when switched on |
| F8 | Free camera |
| W A S D, mouse | Free camera: move, look |
| Space / E, Ctrl / Q | Free camera: up, down |
| Shift | Free camera: faster |
| Page Up / Page Down | Free camera: render distance |
